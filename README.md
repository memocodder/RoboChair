# Robochair RL Project

Этот проект посвящен разработке и экспериментам с алгоритмами Reinforcement Learning (RL) для управления симулированным роботом Robochair.

## Философия и Архитектурный Подход

При разработке этого проекта был сделан **осознанный выбор** в пользу создания **собственной гибкой и модульной структуры**, а не использования исключительно высокоуровневых RL-библиотек (таких как Stable Baselines3) "из коробки".

**Основная мотивация этого подхода:**

1.  **Максимальная Гибкость:** Получить полный контроль над всеми компонентами системы — от определения среды и обработки наблюдений (включая кастомные гриды восприятия) до тонкой настройки или модификации самих RL-алгоритмов.
2.  **Глубокая Интеграция:** Возможность тесно связывать специфические компоненты симуляции (физика Genesis/MuJoCo/Brax, кастомные награды, сброс состояний) с циклом обучения RL.
3.  **Исследовательский Потенциал:** Упрощение экспериментов с нестандартными архитектурами сетей, новыми алгоритмами или их гибридами.
4.  **Прозрачность:** Лучшее понимание всего процесса обучения "end-to-end", без "черных ящиков".

**Компромисс:** Такой подход требует **больших начальных затрат времени** на проектирование структуры, создание системы конфигурации и реализацию некоторых базовых компонентов (например, циклов обучения), по сравнению с использованием готовых библиотечных решений. Однако ожидается, что эта начальная инвестиция окупится при дальнейшей разработке, кастомизации и отладке сложных экспериментов.

Идея не в том, чтобы полностью игнорировать существующие библиотеки, а в том, чтобы иметь возможность **интегрировать или адаптировать** их части в рамках своей контролируемой структуры, когда это необходимо.

## Структура Проекта (Краткий Обзор)

* **`configs/`**: Центральное место для конфигурации всего проекта с использованием **Python датаклассов**. Это позволяет гибко настраивать эксперименты, не меняя основной код.
    * `configs/robots/`: Определения **структуры** роботов (URDF, список DoF и их порядок).
    * `configs/environment/`: Конфигурации **сред** для разных бэкендов (Genesis, MuJoCo...). Включают настройки **экземпляра** робота (начальное состояние, управление, физика), конфигурации его сенсоров (гриды) и других компонентов (цели, препятствия).
    * `configs/algorithm/`: Конфигурации **алгоритмов** (PPO, Diffusion...). Включают гиперпараметры алгоритма, структуру его нейронных сетей (политики) и параметры **специфичного для него процесса обучения** (например, параметры цикла PPO или параметры обучения диффузионной модели на датасете).
    * `configs/experiments/`: Конфигурации **конкретных экспериментов**. Каждый файл здесь объединяет конфигурацию среды, конфигурацию алгоритма и общие настройки запуска (логирование, сиды), создавая полный набор параметров для одного запуска.
* **`robochair/`** (или `src/`): Основной **исходный код** проекта (реализации классов сред, роботов, алгоритмов, утилит и т.д.).
* **`scripts/`**: **Скрипты-точки входа** для запуска основных задач (обучение, оценка, сбор данных и т.п.). Они загружают конфигурацию из `configs/experiments/` и запускают соответствующий процесс.

## Дорожная Карта Проекта (Roadmap)

Этот раздел описывает текущий статус проекта и планируемые шаги по развитию.

**Фаза 0: Фундамент и Базовая Функциональность (✓ Выполнено)**

* [x] Настройка Структуры Проекта и Конфигурации (Dataclasses).
* [x] Базовая Среда (Genesis, простые коридоры).
* [x] Простое Восприятие (2D/плоский грид, привязанный к миру).
* [x] Обучение базового агента PPO (навигация к цели).
* [x] Сбор демонстрационных эпизодов с PPO.
* [x] Первичное обучение диффузионной модели (BC) на PPO-эпизодах.

**Фаза 1: Улучшение Среды и Восприятия (Ближайшие Задачи)**

* [ ] **Улучшение Грида Восприятия:**
    * [ ] Реализовать привязку грида к роботу (учет наклона/крена).
    * [ ] Добавить поддержку 3D грида (настраиваемая высота, неравномерные ячейки).
    * [ ] Базовый учет рельефа (ступени, пандусы) в гриде.
* [ ] **Процедурная Генерация Базовых Окружений:**
    * [ ] Реализовать **случайную генерацию** простых планировок (коридоры переменной ширины/длины, базовые комнаты).

    * [ ] Настроить параметры генерации (диапазоны размеров, частота появления элементов) через конфиги среды.
* [ ] **Базовая Окклюзия:**
    * [ ] Реализовать простую модель окклюзий для грида.
* [ ] **Повторное Обучение PPO:**
    * [ ] Обучение/тюнинг PPO в процедурно генерируемых средах с улучшенным гридом.
