# Robochair RL Project

RL-эксперименты для Robochair с использованием Diffusion Policy.

## Требования

- Python 3.10
- PyTorch ([https://pytorch.org/get-started/locally/](https://pytorch.org/get-started/locally/))

## Установка

```bash
# 1. Клонировать репозиторий
git clone https://github.com/memocodder/RoboChair.git
cd RoboChair


# 2. Создать/активировать venv (рекомендуется)
# python -m venv venv && source venv/bin/activate

# 3. Установить зависимости
pip install -r requirements.txt
```

## Как попробовать / Пример рабочего процесса

**Важно:** Этот проект находится в стадии активной разработки и экспериментов. Конфигурационные файлы (`configs/`) предоставлены как есть — они работают в определенной степени, но могут требовать доработки или настройки под ваши нужды. Отнеситесь к ним как к отправной точке. Основная цель репозитория — предоставить основу для запуска скриптов и проведения собственных исследований. Внешний вид и структура кода также находятся в процессе улучшения.

### Шаг 1: Ознакомление с управлением (Ручной режим)

Чтобы просто "поиграть" и освоиться с управлением роботом вручную (используя клавиатуру, как настроено в `genesis-old`), запустите следующий скрипт:

```bash
python scripts/play_and_record.py
```
- На данный момент этот скрипт предназначен в основном для ручного управления.
- В будущем, после доработок среды и симулятора, он потенциально может использоваться для записи экспертных траекторий вручную.

### Шаг 2: Запись данных (Эпизодов) для Diffusion Policy

Диффузионной модели для обучения нужны данные экспертных (или просто хороших) траекторий. Можно использовать обученную PPO политику (или даже ручное управление из предыдущего шага) для сбора этих данных. Скрипт ppo_eval_and_record.py предназначен для этого:

```bash
python scripts/ppo_eval_and_record.py
```

- Этот скрипт запустит сразу 100 параллельных сред и быстро соберет данные.
- Он должен записать 400 эпизодов (этого количества достаточно для минимального обучения диффузионной модели).
- Убедитесь, что данные сохраняются в папку, которую потом будет использовать датасет (например, data/episodes_ppo).


### Шаг 3: Обучение Diffusion Policy
Используя данные, записанные на Шаге 2, запустите обучение диффузионной модели:

```bash
python scripts/train_diffusion.py
```

- Этот скрипт, использует DiffusionRunner. Следите за выводом в консоли, чтобы оценить процесс обучения.
- Чекпоинты модели будут сохраняться в директорию, указанную в конфигурации.

### Шаг 4: Оценка Diffusion Policy
После обучения (или загрузив готовый чекпоинт), оцените производительность обученной диффузионной политики:

```bash
python scripts/eval_diffusion.py
```

### Замечания
- Скорость Инференса: Диффузионные модели могут быть медленными на этапе генерации действий (инференса) из-за многошагового процесса обратной диффузии. Для реального времени это может быть проблемой.
- Использование Траектории: Текущая реализация, использует только первое предсказанное действие из всей сгенерированной траектории (horizon).


### (Опционально) Обучение PPO
Если вы хотите поэкспериментировать с обучением самой PPO политики:

```bash
python experiments/train_ppo.py
```
